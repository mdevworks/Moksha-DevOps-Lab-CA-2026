# Automated File Backup and Organization

## Overview
This project automates file backup and organization using PowerShell. It categorizes files by their extensions, creates backup copies, and generates log files to record the automation process.

## Features
- Automatically organizes files into categories such as Documents, Images, Videos, Audio, Archives, and Others.
- Creates timestamped backup folders.
- Generates log files to record successful operations and errors.
- Supports repeated execution for newly added files.

## Technologies Used
- PowerShell
- Windows Command Prompt
- Git and GitHub

## Project Structure
- `Inbox/` – Source files to be organized.
- `Organized/` – Files organized by category.
- `Backup/` – Backup copies of processed files.
- `Logs/` – Automation log files.
- `Screenshots/` – Project testing evidence.
- `Scripts/` – PowerShell automation script.

## How to Run
1. Place test files inside the `Inbox` folder.
2. Open PowerShell in the project directory.
3. Execute the PowerShell automation script from the `Scripts` folder.
4. Check the `Organized`, `Backup`, and `Logs` folders to verify the results.
